Built from the planner's engine list and the survey's own CSV export, one pull per manufacturer. Counts cover every report filed against that motor's common name at any review status — except half-A motors, which the survey files under the full-A name and which are counted by exact designation instead. Rows marked check are motors sold under the same name by more than one maker.

Open any engine for the lot and date codes reporters copied off the motor. The same lot gets transcribed every which way — a 08 18 11, a081811 — so codes are matched on letters and digits alone and counted once; ×n is how many reports cite that lot, and a teal edge marks three or more. Search a code and the panel drops the overview for just the lots that matched, listing every report behind them — failure date, the lot exactly as the reporter wrote it, designation, failure, location and review status — newest first. Any column heading sorts — click once to order by it, again to reverse; blanks stay at the bottom either way. A repeated lot is a hint, not a verdict — a widely sold lot flies more. Verify anything safety-critical at motorcato.org.
